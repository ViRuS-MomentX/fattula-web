# fattula-web

Сайт fattula на Next.js. Три раздела: главная, посты и проекты.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшен-сборка
```

## Как добавить пост

Быстрее всего скопировать готовый шаблон: `content/posts/_template.md` (для проекта — `content/projects/_template.md`). Файлы, которые начинаются с `_`, на сайт не попадают.

Создайте файл `content/posts/<адрес-поста>.md`:

```md
---
title: Название поста
excerpt: "Пара предложений для списка постов"
date: 2026-10-01
tags: [заметки, дизайн]
---

Текст поста в Markdown.
```

Имя файла станет адресом страницы: `/posts/<адрес-поста>`.
Если в `excerpt` есть двоеточие, возьмите текст в кавычки.

## Как добавить проект

Создайте файл `content/projects/<адрес-проекта>.md`:

```md
---
title: Название проекта
excerpt: "Короткое описание для списка"
date: 2026-10-01
category: Веб
link: https://example.com       # необязательно, кнопка «Открыть проект»
cover: /images/cover.jpg        # необязательно, иначе обложка нарисуется сама
archived: false                 # true — проект уйдёт в «Архив»
---

Подробное описание проекта.
```

Картинки кладите в папку `public/`, например `public/images/cover.jpg` → `cover: /images/cover.jpg`.

> Проекты в `content/projects/` (кроме «Этот сайт») — демонстрационные. Замените их на свои.

## Что есть на сайте

**Главная**
- надпись fattula: буквы жирнеют рядом с курсором, на телефоне по ней бежит волна, по буквам можно кликать;
- карусель предметов из игр и сериалов: свайп, стрелки, точки и клавиши ← →; предметы можно крутить мышью, а увиденные попадают в коллекцию;
- бегущая строка с темами постов и проектов, стеклянные фигуры и шлейф искр за курсором.

**Посты и проекты**
- карточка свежего поста, список по годам, фильтры по темам и категориям;
- проекты в виде списка или сетки, страница проекта с карточкой «О проекте»;
- в постах: оглавление, якоря у заголовков, кнопка «Копировать» у кода, увеличение картинок, размер текста А−/А+, «продолжить чтение» и «Поделиться»;
- переход с обложкой между списком и страницей, обложки проектов рисуются из названия.

**Везде**
- поиск по `Ctrl + K` или `/`, горячие клавиши (`?` покажет список), архив проектов, RSS-лента;
- светлая и тёмная тема, четыре оттенка фиолетового, спокойный режим без анимаций (переключатели в подвале);
- на телефоне вкладки внизу экрана, версия для печати, картинки-превью для ссылок, `sitemap.xml`;
- пасхалки: код Konami, слово fattula на клавиатуре и мини-игра на странице 404.

## Публикация

Сайт публикуется на GitHub Pages: https://virus-momentx.github.io/fattula-web/

Каждый пуш в `main` запускает `.github/workflows/deploy.yml`: он собирает статическую
версию сайта (папка `out/`) и выкладывает её. Один раз нужно включить Pages:
**Settings → Pages → Source: GitHub Actions**.

Переменные окружения при сборке:

- `NEXT_PUBLIC_BASE_PATH` — подпапка сайта, для GitHub Pages это `/fattula-web`;
- `NEXT_PUBLIC_SITE_URL` — полный адрес сайта для RSS и превью ссылок.

Если сайт переедет на свой домен, уберите `NEXT_PUBLIC_BASE_PATH` из workflow.

## Настройка

Контакты в подвале (Telegram, GitHub, почта) добавляются в `lib/format.ts`, в списке `CONTACTS`. Пока он пуст, блок «Контакты» не показывается.

Цвета и шрифты находятся в начале `app/globals.css`.
